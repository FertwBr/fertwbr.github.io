# Pixel Compass - ヘルプおよびよくある質問

Pixel CompassのヘルプおよびFAQページへようこそ！私たちの目標は、お客様が正確かつスタイリッシュに世界をナビゲートし、最大限の体験を得られるようサポートすることです。

## はじめに {: data-toc-key="getting_started" }

### 1. Pixel Compassにはどのような権限が必要ですか？またその理由はなんですか？

Pixel Compassの優れた機能を有効にするには、**正確な位置情報**の権限が必要です。

- **真北の精度:** 正確な地理的北を読み取るために、局地的な磁気偏角を計算します。
- **気象および環境データ:** 動的情報カード（Dynamic Info Cards）用に、現地の天気、現在地の名前、標高データを取得します。
- **Pixel Compass+ウィジェット:** バックグラウンドで正確かつ関連性の高いデータを用いてウィジェットを更新するには、位置情報が必要です。

当社の**スマートインサイトおよびスナップショット（At a Glance）機能**をご利用いただく場合、アプリは以下の**オプション**の権限を要求することがあります。
- **通知へのアクセス:** お気に入りの時計アプリ（Google、Samsung、Xiaomiなどに対応）の実行中のタイマーやアラームのライブカウントダウンをウィジェットが取得して表示するために必要です。
- **カレンダーへのアクセス:** 今後24時間以内の次の予定をウィジェットに表示できるようにします。
- **Bluetooth（接続）:** 周辺機器（イヤホン、スピーカー）の接続をウィジェットが検知し、そのバッテリー残量を表示できるようにします。
- **カメラ（ライト）:** ライトが点灯しているときに、ウィジェットがアクティブなアラートを表示できるようにします。

> お客様の位置情報および個人データは、ご使用のデバイス上で厳密にローカル処理されます。位置情報の履歴やカレンダーの予定が保存または追跡されることは一切ありません。これらの権限は、デバイスの設定またはウィジェットの設定画面から直接、いつでも管理または取り消すことができます。

### 2. メインコンパス画面について

- **コンパスダイヤル:** メインの回転要素です。デバイスの上部が常に進行方向を示します。
- **方位角および基本方位:** 大きな数字は度数で表された進行方向で、その下のテキスト（例: "NW"）は基本方位です。
- **円形情報リング:** 緯度、経度、高度、デバイスの傾斜を一目で確認できます。
- **動的情報カード:** （オプション、設定で有効化）コンパスの下にあるスクロール可能なエリアで、リアルタイムの位置情報や天気などを表示します。
- **スナップショット（At a Glance）機能の操作:** （v1.13.0以降）画面の特定の領域をタップすると「分割（Split）」レイアウトが表示され、気象アラートとスマートインサイトが並んで表示されます。
- **クイックアクションバー（FAB）:** 真北、キャリブレーション、テーマの切り替えにすばやくアクセスできるフローティングボタンです。

## 水準器画面の使用 {: data-toc-key="level" }

### 1. 再設計された水準器画面はどのように機能しますか？

水準器画面は、表現力豊かなアニメーションを使用し、デバイスの持ち方に適応する強力なツールです。

- **フラットモード（ブルズアイ）:** デバイスを表面に上向きにして置くと、波紋効果を伴う「ブルズアイ（的の中心）」の水準器が表示されます。形を変える流動的な気泡を中央に合わせることが目的です。
- **リニアモード（直立）:** デバイスを直立（縦または横）に持つと、波のような流動的な背景を持つ直線的な「気泡管」水準器が表示されます。気泡を`0°`のマークの中央に合わせることが目的です。

### 2. 水準器が正確であることを確認するにはどうすればよいですか？

水準器ツールはコンパスと同じモーションセンサーを使用します。最良の結果を得るには、スマートフォンを既知の平らな表面に置き、メインコンパス画面の**キャリブレーション（Calibrate）**ボタンを使用してください。8の字を描く動作を行うことで、すべてのモーションベースの機能の精度がリセットされ、向上します。

## Wear OS版 Pixel Compass {: data-toc-key="wearos" }

- **スタンドアロンのエクスペリエンス:** Wear OSアプリは完全に独立しており、時計独自のセンサーを使用します。
- **コンパスタイル:** （v1.8.0以降）コンパスタイルを時計のカルーセルに追加すると、アプリ全体を開くことなく、最後に確認された進行方向と現在の高度の「スナップショット」をすばやく確認できます。
- **カスタマイズ:** AMOLEDブラック、エメラルド、サンセットなど、**9つの新しいカラーテーマ**（v1.14.0以降）からお選びいただけます。
- **精密ツール:** 時計から直接高度を手動でキャリブレーションしたり、時計を右腕に着用している場合は**コンパスの反転（Compass Inversion）**を切り替えたりすることができます。
- **高度の信頼性と自動修復（Auto-Healing）:** 時計は気圧の変動（ドリフト）をアクティブに監視します。高度の信頼性レベル（高、中、低）を視覚的に表示し、以前に手動でキャリブレーションを行った場所に戻った際に「自動修復」（シームレスな再キャリブレーション）を行うことができます。
- **インストール:** ペアリングしたスマートフォンのGoogle Playアプリ経由で、または時計のGoogle Playから直接インストールしてください。

## Pixel Compass+ およびウィジェット {: data-toc-key="plus" }

### 1. Pixel Compass+ とは何ですか？

Pixel Compass+は、柔軟なサブスクリプションまたは生涯ライセンスを通じて利用できる、当社のpremium機能セットです。これによりアプリの可能性を最大限に引き出し、今後の開発をサポートします。

### 2. 主なPlusの機能は何ですか？

- **インサイトエンジン 4.0:** 「ピクニック日和」、「強風」、「気圧低下」などのプロアクティブなアラート（v1.12.0以降）。
- **詳細なカスタマイズ:** premiumコンパススタイル（`Sunny`、`Cookie`、`Flower`）、高度なカードパックの形状、および**AMOLEDブラック**のアプリテーマのロックを解除します。
- **予報チャート:** 任意の天気カードをタップすると、気温、降水量、および**太陽の軌道**のインタラクティブな時間別チャートが表示されます。
- **究極のウィジェットスイート:** 限定の形状（モダン、ピル、アーチ、クッキー）と、ネイティブのバッテリー効率を備えた**時計ウィジェット**（v1.14.0以降）にアクセスできます。
- **インタラクティブな風向計:** コンパスローズ上のリアルタイム風向計です。
- **広告なしの体験:** すべての広告を削除し、集中できる体験を提供します。
- **設定のバックアップ:** Plusの環境設定は自動的にクラウドにバックアップされ、ワンタップで復元できます（v1.9.5以降）。

### 3. サブスクリプションはどのように機能しますか？すでに支払っている場合はどうなりますか？

- **新規ユーザー:** Pixel Compass+は、低価格の月額サブスクリプションでご利用いただけます。
- **レガシーユーザー:** **バージョン1.7.2より前**に買い切り購入された場合、**レガシーステータス**となります。すべてのPlus機能への**無料の生涯アクセス**が提供されます。
- **生涯オプション:** サブスクリプションを希望されない方向けに、「生涯購入（買い切り）」のオプションが用意されています。

### 4. ウィジェットを追加して設定するにはどうすればよいですか？

1. **追加:** ホーム画面を長押しし、「ウィジェット」を選択して、Pixel Compassを探します。
2. **設定:** モダンな設定画面が開きます。**タイプ**（高度、コンパス、天気など）と**形状**を選択できます。
3. **スナップショット（At a Glance）システム統合:** 当社のスマートウィジェットで、ライブのシステムイベントが表示できるようになりました！ウィジェットの設定画面から、以下を個別に有効または無効にできます。
   - **カレンダー:** 次の予定を確認します。
   - **アラームおよびタイマー:** 実行中のタイマーまたは今後のアラームのライブカウントダウンを確認します。
   - **Bluetooth:** 接続されているイヤホンとスピーカーのバッテリー残量を確認します。
   - **バッテリーおよびライト:** バッテリー残量低下時、充電中、またはライトが誤って点灯したままになっている場合にアラートを受け取ります。
4. **リアルタイム更新:** 高頻度の更新により、ホーム画面上で直接スムーズな針のアニメーションが提供されます。
5. **ベストプラクティス:** 信頼性を高めるために、デバイスのバッテリー設定でPixel Compassが「制限なし」に設定されていること、および使用する統合機能の通知／権限が有効になっていることを確認してください。

## スマートインサイトおよび気象アラート {: data-toc-key="smart_alerts" }

Pixel Compassは、単なる生の数値を表示するだけでなく、周囲の環境をアクティブに解釈します。新しく再設計されたシステムは、ポケットの中の気象学者として機能し、お客様を快適、安全、かつ情報に富んだ状態に保ちます。

### 1. インサイトエンジン（動的カード）
動的カードを有効にすると、アプリは現在の状況、時間別の傾向、日々の予報を処理し、人に優しく実用的なアドバイスを提供します。
- **快適性およびライフスタイル:** 洗車の最適なタイミングを提案したり、「オーブン効果」による熱を警告したり、空気が乾燥しすぎて肌や髪に悪影響がある場合にアラートを出したりします。
- **レジャー計画:** 雲量、気温、風の複雑な組み合わせに基づいて、「ピクニック日和」、「天体観測」、「スキーコンディション」を推奨します。
- **観測:** 「ゴールデンアワー」、「鮮やかな空」、特定の月相など、美しい自然現象をハイライト表示します。
- **カスタマイズ:** **設定 > 動的カード > インサイトカテゴリの管理**から、表示するインサイトの種類（アラート、健康、快適性、アクティビティ、観測）をフィルタリングできます。

### 2. スマート気象アラート（プッシュ通知）
有効にすると、Pixel Compassはアプリが閉じているときでも、重要かつタイムリーな警告をスマートフォンの通知シェードに直接送信できます。
- **荒天アナライザー:** 濃霧、急激な紫外線による日焼けのリスク、ハイドロプレーニング現象の高い発生確率、差し迫った雷雨などの極端なシナリオを自動的に検知します。
- **降水トラッキング:** 大雨や雪がいつ降り始めるか、または止むかを正確にお知らせします。
- **天文アラート:** 日の出や日の入りが近づいているときに通知を受け取ります。
- **スマートクールダウン:** 通知の疲れを防ぐため、システムはインテリジェントなクールダウンタイマーを使用し、同じアラートが1日に何度もスパムのように送信されないようにします。
- **アラートの管理:** **設定 > 通知およびアラート**から、これらの通知を切り替え、アラートのカテゴリ（例: 健康リスク、降水、天文、深刻なアラート）をカスタマイズできます。

## 高度およびキャリブレーション {: data-toc-key="altitude" }

### 1. 高度はどのように計算されますか？

Pixel Compassは、極めて高い精度とバッテリー効率を両立させるために、スマートなマルチソースエンジンを使用しています。

- **気圧計（プライマリ）:** デバイスに気圧センサーが搭載されている場合、これを使用してリアルタイムかつ高感度な高度の変化を追跡します。
- **標高API（ベースライン）:** 気圧計の正確なベースラインを設定するために、地形データサーバーに定期的にpingを送信します。
- **GPSフォールバック:** インターネット接続や気圧計がない場合、またはネットワークAPIが一時的に利用できない場合に自動的に使用されます。

### 2. 高度のキャリブレーションはいつ行うべきですか？

ほとんどの場合、**行う必要はありません**。長距離を移動する際、Pixel Compassはバックグラウンドで自動的に高度を確認し、再キャリブレーションを行います。

- **スマートリフレッシュ:** **設定 > 高度**から手動のネットワークチェックを強制実行できます。データとバッテリーを節約するため、高度が「最適化済み」（最近キャリブレーションが行われ、更新の必要がないことを意味します）である場合はアプリが通知します。
- **手動キャリブレーション:** 正確な標高がわかっている場合（例: 登山道の標識や地図などから）、**設定 > 高度**に手動で入力することで、絶対的でプロフェッショナルなレベルの精度を得ることができます。これは、お客様が削除を決定するまで、自動チェックを完全にオーバーライドします。

### 3. 高度の信頼性と自動修復（Auto-Healing）とは何ですか？

気圧は天候によって常に変化する（気圧のドリフト）ため、高度の読み取り値は数時間から数日の間に徐々に精度を失う可能性があります。
- **信頼性レベル:** アプリは信頼性レベル（高、中、低）と特定のドリフト警告を表示し、天候の変化により手動キャリブレーションが古くなっている可能性があるかどうかをお知らせします。
- **自動修復:** 自宅で高度を手動キャリブレーションした後、外出して数時間後に戻ってきた場合、アプリの**自動修復**システムが既知の場所に戻ったことを検知します。気圧のドリフトを自動的かつ静かに修正し、指一本動かすことなく高度の精度を回復します！

### 4. コンパス（方向）のキャリブレーションはどうすればよいですか？

コンパスの針が飛ぶように動く、動かない、または間違った方向を指している場合は、メイン画面の**キャリブレーション（Calibrate）**ボタンをタップし、デバイスを3つの軸すべてに沿って回転させながら**8の字（∞）**のパターンで動かします。デバイスを磁石、重機、または磁気留め金のある厚いスマートフォンケースから遠ざけてください。

## トラブルシューティングおよびFAQ {: data-toc-key="troubleshooting" }

- **アプリをダウンロードまたは更新できなくなったのはなぜですか？（デバイスが非互換）**
    - バージョン**1.19**以降、Pixel Compassを機能させるには、物理的なハードウェアコンパスセンサー（磁力計）が厳密に必要となります。Google Playのシステム要件を更新してこのルールを適用し、ユーザーがデバイスで動作しないアプリをインストールできないようにしました。
- **Pixel Compass+を購入したのに、デバイスが非互換になった場合はどうなりますか？**
    - Plusユーザーであり、お使いのデバイスに磁力計が搭載されていない場合は、Google Playの購入コード（注文ID）を添えて**suport@fertwbr.com**までご連絡ください。特にGoogle Playの標準の返金期間がすでに過ぎている場合や、Googleによって返金リクエストが拒否された場合でも、手動での返金処理を行います。
- **コンパスセンサーがなくても、古いバージョン（v1.18.3）を使い続けることはできますか？**
    - はい。すでにバージョン1.18.3がインストールされている場合は、引き続きご使用いただけます。水準器ツールや天気カードなど、コンパスハードウェアに依存しない機能は正常に機能するはずです。ただし、デバイスに物理的に必要なセンサーがないため、コンパス自体は引き続き機能しません。
    - ご注意: バージョン1.18.3は無期限に使い続けることができますが、利用できるのはそのバージョンが公式に廃止されるまで（例えば、当社の気象データプロバイダーがAPIを変更した場合や、重要なセキュリティアップデートが必要になった場合など）となります。
- **コンパスが動かない、または不正確です。**
    - スマートフォンケースに磁石が含まれていないことを確認してください。大きな金属製のものから離れた場所で8の字のキャリブレーションを実行してください。
- **天気に「サポートされていない場所です（Location Not Supported）」と表示されます。**
    - 一部の地域では、Weather APIのデータカバレッジがない場合があります。設定で天気機能を無効にして、エラーを非表示にすることができます。
- **ウィジェットが更新されません。**
    - 「バッテリー最適化」によってアプリが強制終了されていないか確認してください。Pixel Compassを「制限なし」に設定し、位置情報の権限を「常に許可」にしていることを確認してください。

### 気象プロバイダーおよび地域サポート

**1. アプリはGoogle WeatherとOpenWeatherをどのように選択しますか？**
バージョン1.19.0以降、Pixel Compassはグローバルなカバレッジを確保するために、多層的な気象エンジンを使用しています。
- **Google Weather:** これは当社の主要かつ最も正確なプロバイダーであり、公式にサポートされているすべての地域で使用されています。
- **OpenWeatherMap（フォールバック）:** 現在の地域がGoogle Weatherでサポートされていない場合、アプリは一貫したデータを提供するために自動的にOpenWeatherMapに切り替えます。
- **サポートされていない地域:** どちらのサービスも特定の座標のデータを提供できない場合、アプリは「互換性のない地域です（Region Not Compatible）」というステータスを表示します。

**2. プロバイダー間でデータが異なって見えるのはなぜですか？**
Google Weatherと比較して、OpenWeatherMapのデータは時折精度が低かったり、特定の指標（詳細な降水タイプや正確なUVインデックスなど）が欠けていたりする場合があります。これは地域によって異なり、利用可能なデータソースの制限によるものです。アプリは、エラーや誤った値を表示するのではなく、欠落している情報を単に非表示にすることで、これらのギャップを適切に処理するように設計されています。

**3. バージョン1.19.0以降も「サポートされていない地域です（Region Not Supported）」と表示されます。**
バージョン1.19.0以降を実行しているにもかかわらず、お住まいの地域が依然としてサポートされていない場合は、当社のサポートチームにご連絡ください。お客様の座標を分析し、その地域において技術的な解決策やサードパーティプロバイダーの統合が可能かどうかを確認いたします。

**4. サポートされていない地域のPlusユーザーです。どうすればよいですか？**
Pixel Compass+のサブスクリプション登録者であり、高品質の気象データが登録の主な理由であった場合、現在お住まいの地域がサポートされていないことへのご不満はお察しいたします。今後のアップデートを待ちたくない場合は、**suport@fertwbr.com**までご連絡のうえ、返金をご請求ください。私たちは皆様のサポートを大切にしており、ご購入にご満足いただけるようにしたいと考えております。
