# Version History
Track the evolution of Pixel Measure. Here you'll find a detailed log of new features, improvements, and fixes for each version.

## Version 1.0.0
*(Released August 17, 2026)*

Welcome to the initial release of Pixel Measure! This is a temporary placeholder while the application is actively being prepared for its first public launch.

#### 📱 Phone
* **New: Core AR Engine:** Implemented the foundational Augmented Reality tracking system using ARCore.
* **New: Basic Measurements:** Added the ability to place spatial anchors and calculate straight-line distances in real-time.
* **UI & UX Polish:** Established the initial Material 3 design system, including the immersive camera view and dynamic color theming.
* **Under the Hood:** Initialized the local Room database to handle future session history saving.
