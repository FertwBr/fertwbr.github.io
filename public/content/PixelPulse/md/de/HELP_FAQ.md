# Pixel Pulse - Hilfe & Häufig gestellte Fragen {: data-toc-key="top" }

Willkommen auf der Hilfe- und FAQ-Seite von Pixel Pulse! Unser Ziel ist es, Ihnen zu helfen, Ihre akustische Umgebung mit Präzision und Klarheit zu messen und zu verstehen, egal ob auf Ihrem Telefon oder an Ihrem Handgelenk.

## Erste Schritte {: data-toc-key="getting-started" }

### 1. Den Hauptmessbildschirm verstehen {: data-toc-key="main-screen" }
-   **Dezibel-Anzeige:** Das große, halbkreisförmige Messgerät bietet eine visuelle Echtzeitanzeige des aktuellen Schallpegels. Die Farbe ändert sich dynamisch, um Ihnen einen sofortigen Kontext zu geben.
-   **Sitzungsstatistiken:** Die Anzeigen MIN, AVG und MAX zeigen die Statistiken für Ihre aktuelle Aufnahmesitzung an.
-   **Aktionsschaltflächen:**
    -   **Stopp/Fortsetzen:** Die primäre Schaltfläche, um die Messung anzuhalten und fortzusetzen.
    -   **Neustart:** Setzt alle Sitzungsstatistiken und den Timer zurück.
    -   **Symbolleiste:** Symbole für den Schnellzugriff auf Kalibrierung, Speichern und diesen Info-Leitfaden.

### 2. Wie funktioniert die Kalibrierung? {: data-toc-key="calibration" }
Das **Kalibrierungs**-Tool ermöglicht es Ihnen, die Messwerte der App fein abzustimmen. Wenn Sie Zugang zu einem professionellen Schallpegelmessgerät haben, können Sie den Schieberegler im Kalibrierungsdialog verwenden, um einen positiven oder negativen Offset anzuwenden (z. B. -2,5 dB). Dieser Offset wird auf alle zukünftigen Messungen (Telefon und Uhr) angewendet, um die Genauigkeit zu verbessern. Dies ist eine kostenlose Funktion für alle Benutzer.

## Sitzungsverlauf {: data-toc-key="session-history" }

### 1. Wie speichere und verwalte ich Sitzungen? {: data-toc-key="manage-sessions" }
Nachdem Sie eine Aufnahme pausiert haben, tippen Sie auf das **Speichern**-Symbol. Drücken Sie auf dem Verlaufsbildschirm **lange** auf eine beliebige Sitzung, um in den Auswahlmodus zu gelangen. Auf diese Weise können Sie mehrere Aufnahmen auswählen, um sie alle auf einmal zu löschen oder als Favoriten zu markieren. Sitzungen, die auf Ihrer Wear OS-Uhr aufgezeichnet wurden, werden nach der Synchronisierung ebenfalls hier angezeigt.

### 2. Wie exportiere ich meine Daten? {: data-toc-key="exporting" }
Auf dem Bildschirm mit den Sitzungsdetails können Sie das Menü verwenden, um Ihre Daten zu exportieren.
-   **Als Text kopieren:** Diese kostenlose Option kopiert eine einfache Zusammenfassung der Sitzung in Ihre Zwischenablage.
-   **Als CSV exportieren `[Plus+]`:** Diese premium-Funktion speichert ein vollständiges, mit Zeitstempeln versehenes Protokoll des Dezibel-Verlaufs der Sitzung in einer CSV-Datei, ideal für die Analyse in Tabellenkalkulationssoftware.

## Wear OS-Begleit-App {: data-toc-key="wear-os" }

Die Pixel Pulse-App für Wear OS ist für schnelle Interaktionen und eigenständige Aufnahmen konzipiert. Hier erfahren Sie, wie Sie durch die Benutzeroberfläche navigieren:

### 1. Eigenständige Aufnahme {: data-toc-key="wear-recording" }
Sie können Sitzungen direkt auf Ihrer Uhr aufzeichnen, ohne dass Ihr Telefon in der Nähe ist. Die Benutzeroberfläche ist für AMOLED-Bildschirme optimiert, um den Akku zu schonen. Wenn Sie eine Aufnahme auf der Uhr beenden, können Sie diese lokal speichern.

### 2. Synchronisierung {: data-toc-key="wear-sync" }
Wenn sich Ihre Uhr wieder mit Ihrem Telefon verbindet, können Ihre gespeicherten Sitzungen automatisch auf die Registerkarte „Verlauf“ der Telefon-App übertragen werden. Sie können dieses Verhalten unter **Einstellungen > Synchronisierung & Backup** auf Ihrer Uhr konfigurieren.

### 3. Grundlagen der Navigation {: data-toc-key="wear-nav" }
Die App verwendet ein **horizontales Layout**, um ihre Hauptfunktionen zu organisieren. Wischen Sie nach **links** oder **rechts**, um zwischen den Bildschirmen zu wechseln:
-   **Mitte:** Das Hauptmessgerät.
-   **Rechts:** Sitzungsverlauf.
-   **Ganz rechts:** Einstellungen.

### 4. Verwendung des Hauptmessgeräts {: data-toc-key="wear-meter" }
-   **Aufnahme starten:** Tippen Sie auf die große **Play**-Schaltfläche, um die Überwachung zu starten.
-   **Immersiver Modus:** Tippen Sie während der Aufnahme auf den **Bildschirm**, um die Tasten Stopp/Speichern auszublenden. Dadurch wird die Dezibel-Anzeige vergrößert und Live-Statistiken (Min/Avg/Max) werden angezeigt. Tippen Sie erneut, um die Steuerelemente anzuzeigen.
-   **Schnellinformationen:** Wischen Sie vom unteren Rand nach **oben**, um spezifische Details zum aktuellen Sitzungslayout oder Tipps anzuzeigen.

### 5. Verlauf & Details anzeigen {: data-toc-key="wear-history" }
Wischen Sie zum Bildschirm **Verlauf**, um Ihre Liste der Aufnahmen anzuzeigen.
-   **Sitzungsplayer:** Tippen Sie auf eine beliebige Sitzung, um die Details zu öffnen. Der erste Bildschirm zeigt ein Diagramm und Wiedergabesteuerungen.
-   **Sitzungsaktionen:** Wischen Sie auf dem Detailbildschirm nach **oben**, um das Aktionsmenü anzuzeigen. Hier können Sie diese spezifische Sitzung **umbenennen**, **löschen**, **als Favorit markieren** oder manuell mit Ihrem Telefon **synchronisieren**.

### 6. Einstellungen & Anpassung {: data-toc-key="wear-settings" }
Wischen Sie zum Bildschirm **Einstellungen** (ganz rechts), um Ihr Erlebnis zu konfigurieren:
-   **Messgeräteeinstellungen:** Passen Sie die Aktualisierungsgeschwindigkeit und die Frequenzbewertung an `[Plus+]` oder kalibrieren Sie das Mikrofon.
-   **Anpassung:** Ändern Sie die Designfarbe der App, um sie an Ihr Zifferblatt anzupassen.
-   **Synchronisierung & Backup:** Konfigurieren Sie, ob Sitzungen automatisch synchronisiert werden sollen.

## Pixel Pulse+: Lärmexposition & Warnungen {: data-toc-key="plus-features" }

Die Registerkarte „Exposition“ ist das Herzstück des Pixel Pulse+-Erlebnisses. Sie verwandelt die App in einen automatisierten Coach für die Hörgesundheit.

### 1. Was ist die Lärmexpositionsanalyse? {: data-toc-key="exposure-analysis" }
Wenn Sie diese `[Plus+]`-Funktion aktivieren, arbeitet die App leise im Hintergrund und nimmt regelmäßige Tonproben, um ein Bild Ihrer Umgebung zu erstellen. Dies speist einen speziellen Bildschirm mit mehreren Komponenten:
-   **Tages-, Wochen- und Monatsdiagramme:** Sehen Sie sich Ihre Klangmuster über verschiedene Zeiträume an.
-   **Wöchentliches Lärmbudget:** Ein visuelles Tool basierend auf WHO-Richtlinien, das Ihnen hilft, Ihre Exposition gegenüber lauten Geräuschen (über 80 dB) zu verwalten.
-   **Panel für wichtige Metriken:** Sehen Sie Ihre durchschnittlichen dB, Spitzenwerte und die lautesten/leisesten Zeiten der letzten 24 Stunden.
-   **Personalisierte Einblicke:** Die App bietet kontextbezogene Tipps und Beobachtungen basierend auf Ihren Datentrends.

### 2. Wie funktionieren Lärmwarnungen? {: data-toc-key="noise-alerts" }
Lärmwarnungen `[Plus+]` sind eine proaktive Sicherheitsfunktion. In den Einstellungen des Expositionsbildschirms können Sie ein **Lärmlimit** (z. B. 85 dB) und eine **Warnungsdauer** (z. B. 15 Minuten) festlegen. Wenn der Hintergrundmonitor erkennt, dass Sie sich länger als die angegebene Dauer in einer Umgebung befunden haben, die dieses Limit überschreitet, sendet er Ihnen eine Benachrichtigung, die Sie daran erinnert, eine Pause einzulegen oder Gehörschutz zu verwenden.

### 3. Was sind die erweiterten `[Plus+]`-Einstellungen? {: data-toc-key="advanced-settings" }
Pixel Pulse+ schaltet mehrere professionelle Einstellungen frei:
-   **Frequenzbewertung (dBC/dBZ):** Während dBA (der Standard für das menschliche Gehör) kostenlos ist, können Plus-Benutzer für technische Analysen auf dBC (für niederfrequenten Lärm) oder dBZ (eine flache, ungewichtete Anzeige) umschalten.
-   **Einstellbare Aktualisierungsgeschwindigkeit:** Steuern Sie, wie schnell das Messgerät reagiert, um die Akkulaufzeit mit der Notwendigkeit abzuwägen, schnelle Klangänderungen zu erfassen.
-   **Umgebungs-Haptik-Feedback:** Aktivieren Sie eine kontinuierliche, subtile Vibration, die mit der Intensität der Umgebungsgeräusche skaliert und so eine einzigartige sensorische Verbindung zu Ihrer Umgebung bietet.

## Datenschutz & Datenverarbeitung {: data-toc-key="data-privacy" }

Ihre Privatsphäre steht an erster Stelle. Hier erfahren Sie genau, welche Daten die App verarbeitet und wie.

### 1. Echtzeitmessung & Gespeicherte Sitzungen (Alle Benutzer) {: data-toc-key="privacy-sessions" }
-   **Wird Audio aufgezeichnet?** Nein. Das Mikrofon wird verwendet, um den Schalldruck zu messen, und das Rohaudio wird sofort verworfen. **Es wird niemals Audio gespeichert.**
-   **Was wird gespeichert?** Wenn Sie eine Sitzung speichern, speichert die App eine Liste berechneter Dezibel-Zahlen (z. B. 65.4, 66.1, 65.9) und Sitzungsstatistiken (Min, Max, Dauer).
-   **Wo wird es gespeichert?** Diese Daten werden in einer privaten, lokalen Datenbank **nur auf Ihrem Gerät** gespeichert. Sie verlassen Ihr Telefon niemals, es sei denn, Sie entscheiden sich, sie zu exportieren.

### 2. Überwachung der Lärmexposition (Benutzer von Pixel Pulse+) {: data-toc-key="privacy-exposure" }
-   **Wie funktioniert das?** Etwa alle 15 Minuten wacht die App für ein paar Sekunden auf, misst den durchschnittlichen Schallpegel und speichert zwei Informationen: einen **Zeitstempel** und eine einzelne **Dezibel-Zahl**.
-   **Wird im Hintergrund Audio aufgezeichnet?** Absolut nicht. Der Prozess ist derselbe wie beim Echtzeit-Messgerät: Messen, Berechnen und sofortiges Verwerfen von Audio.
-   **Wo werden diese Daten gespeichert?** Sie werden ebenfalls in derselben privaten, lokalen Datenbank auf Ihrem Gerät gespeichert.
-   **Werden Daten weitergegeben?** Nein. Alle Analysen, Diagramme und Einblicke werden zu 100 % auf dem Gerät generiert.

### 3. Synchronisierung & Backup (Wear OS) {: data-toc-key="sync-data-privacy" }
-   **Wie werden Daten übertragen?** Wir verwenden die sichere **Android Wearable Data Layer API** (Teil der Google Play-Dienste), um Sitzungsdaten von Ihrer Uhr auf Ihr Telefon zu übertragen.
-   **Werden Daten auf Servern gespeichert?** Nein. Pixel Pulse verfügt über keine eigenen Backend-Server. Der Synchronisierungsprozess erfolgt strikt von **Gerät zu Gerät**.
-   **Was ist mit Cloud Sync?** Wenn Ihre Uhr und Ihr Telefon nicht über Bluetooth verbunden sind, kann das System Google Cloud Sync (verschlüsselt) verwenden, um die Daten über WLAN/LTE weiterzuleiten. Dies wird vollständig vom Android-System gehandhabt, um die Zustellung sicherzustellen; Pixel Pulse greift weder extern auf diese Daten zu noch speichert es sie extern.
-   **Kann ich das deaktivieren?** Ja. Sie können die „Automatische Synchronisierung“ jederzeit im Menü **Einstellungen > Synchronisierung & Backup** auf Ihrer Uhr deaktivieren.

Wir erfassen, teilen und haben **keinerlei** Zugriff auf Ihre Audio- oder Messdaten.

## Manuelles Backup & Wiederherstellung (.ppbk) {: data-toc-key="manual-backup" }

Pixel Pulse bietet ein robustes, datenschutzorientiertes manuelles Backup-System, mit dem Sie Ihre Daten zwischen Geräten übertragen oder Offline-Archive führen können. Dieses System verwendet ein proprietäres Dateiformat: **`.ppbk` (Pixel Pulse Backup)**.

### 1. Was ist eine `.ppbk`-Datei? {: data-toc-key="ppbk-format" }
Eine `.ppbk`-Datei ist ein sicherer, verschlüsselter Container, der Ihren gesamten Pixel Pulse-Verlauf enthält. Im Gegensatz zu einfachen Text- oder CSV-Exporten enthält diese Datei:
-   **Sitzungsaufzeichnungen:** Alle Ihre gespeicherten Audiomesssitzungen.
-   **Expositionsverlauf:** Ihre langfristigen Hintergrundüberwachungsdaten.
-   **Metadaten:** Informationen darüber, welches Gerät (Telefon oder Uhr) die Daten und die App-Version erstellt hat.

### 2. Intelligente Wiederherstellung (Zusammenführungsstrategie) {: data-toc-key="smart-restore" }
Die Wiederherstellung von Daten in Pixel Pulse ist **nicht destruktiv**. Wir verwenden eine "Smart Merge"-Strategie:
-   **Kein Überschreiben:** Durch die Wiederherstellung eines Backups werden Ihre vorhandenen Daten **nicht** gelöscht oder überschrieben.
-   **Duplikaterkennung:** Die App überprüft den eindeutigen Zeitstempel jeder Sitzung und jedes Expositions-Eintrags.
-   **Nahtlose Integration:** Es werden nur Datensätze importiert, die derzeit nicht auf Ihrem Gerät existieren. Auf diese Weise können Sie Daten aus mehreren Backups oder von verschiedenen Geräten kombinieren, ohne Duplikate zu erstellen.

### 3. Sicherheit & Verschlüsselung {: data-toc-key="backup-security" }
Ihre Schalldaten sind sensibel, daher sind unsere Backups standardmäßig verschlüsselt. Sie können eine `.ppbk`-Datei nicht einfach in einem Texteditor öffnen.
-   **Verschlüsselungsstandard:** Wir verwenden **AES-256-GCM** (Advanced Encryption Standard im Galois/Counter Mode) ohne Padding (NoPadding). Dies ist ein branchenüblicher Algorithmus zur Sicherung sensibler Daten.
-   **Integritätsprüfung:** Die Datei enthält einen eindeutigen „Magic Header“ und Initialisierungsvektoren, um sicherzustellen, dass die Datei vor der Entschlüsselung nicht beschädigt oder manipuliert wurde.

### 4. So wird es verwendet {: data-toc-key="using-backup" }
-   **Zum Sichern:** Gehen Sie zu **Einstellungen > Datenverwaltung > Backup**. Dadurch wird eine `.ppbk`-Datei generiert, die Sie in Google Drive speichern, per e-mail senden oder im Dateisystem Ihres Telefons ablegen können.
-   **Zum Wiederherstellen:** Gehen Sie zu **Einstellungen > Datenverwaltung > Wiederherstellen** und wählen Sie eine gültige `.ppbk`-Datei aus. Die App verarbeitet die Datei und teilt Ihnen mit, wie viele neue Elemente importiert wurden.

## Fehlerbehebung & Häufig gestellte Fragen {: data-toc-key="troubleshooting" }

### Warum heißt es "Mikrofon wird von einer anderen App verwendet"? {: data-toc-key="mic-blocked" }
Aus Datenschutz- und Sicherheitsgründen erlaubt das Android-Betriebssystem nur einer App gleichzeitig den Zugriff auf das Mikrofon. Wenn Sie einen Anruf tätigen, eine Sprachnachricht aufzeichnen (z. B. auf WhatsApp) oder die Kamera verwenden, blockiert Android vorübergehend den Zugriff von Pixel Pulse auf die Hardware.
- **Manuelle Aufnahme:** Wenn Sie versuchen, eine Aufnahme zu starten, während das Mikrofon blockiert ist, sehen Sie eine Warnung. Wenn Sie bereits aufnehmen und eine andere App die Kontrolle übernimmt, wird Pixel Pulse Ihre Aufnahme ordnungsgemäß **pausieren**, um Datenverlust zu verhindern.
- **Live- & kontinuierliche Sitzungen:** Wenn eine Hintergrundsitzung ausgeführt wird, wechselt die App in den Status "Warten". Sie überwacht die Hardware lautlos und nimmt das Tracking automatisch **wieder auf**, sobald Ihr Anruf oder Ihre Sprachnotiz beendet ist. Sie müssen nichts tun!
- **Ist das ein Fehler?** Nein, dies ist das Standardverhalten von Android. Wenn Sie sich jedoch absolut sicher sind, dass keine andere App das Mikrofon verwendet und das Problem weiterhin besteht, versuchen Sie, Ihr Gerät neu zu starten. Wenn das Problem weiterhin auftritt, senden Sie uns bitte Feedback über die App!

### Die Hintergrundüberwachung scheint nicht mehr zu funktionieren. {: data-toc-key="background-stop" }
Einige Telefonhersteller verwenden aggressive Energiesparmaßnahmen, die Hintergrund-Apps beenden können. Um eine zuverlässige Überwachung zu gewährleisten, **deaktivieren Sie bitte die Batterieoptimierung** für Pixel Pulse. Die App zeigt ein Banner an, das Sie anleitet, wenn sie erkennt, dass die Optimierung aktiv ist.

### Meine Messwerte scheinen ungenau zu sein. {: data-toc-key="readings-inaccurate" }
Richten Sie für beste Ergebnisse das primäre Mikrofon Ihres Geräts auf die Schallquelle und stellen Sie sicher, dass es nicht verdeckt ist. Verwenden Sie die Funktion **Kalibrierung**, um die Messwerte gegenüber einem Referenzgerät fein abzustimmen.
