# Pixel Pulse - ヘルプとよくある質問 {: data-toc-key="top" }

Pixel Pulse のヘルプおよび FAQ ページへようこそ！私たちの目標は、スマートフォンでもスマートウォッチでも、お客様が音響環境を正確かつ明確に測定し、理解できるようにすることです。

## はじめに {: data-toc-key="getting-started" }

### 1. メインのメーター画面を理解する {: data-toc-key="main-screen" }
-   **デシベルゲージ：** 大きな半円形のメーターは、現在の音量レベルをリアルタイムで視覚的に提供します。その色はダイナミックに変化し、瞬時にコンテキストを把握できます。
-   **セッション統計：** MIN（最小）、AVG（平均）、MAX（最大）の表示は、現在の録音セッションの統計を示します。
-   **アクションボタン：**
    -   **停止/再開：** 測定を一時停止したり続行したりするためのメインボタンです。
    -   **再起動：** すべてのセッション統計とタイマーをリセットします。
    -   **ツールバー：** キャリブレーション、保存、およびこの情報ガイドにすばやくアクセスするためのアイコンです。

### 2. キャリブレーションの仕組み {: data-toc-key="calibration" }
**キャリブレーション（校正）** ツールを使用すると、アプリの測定値を微調整できます。プロ用の騒音計にアクセスできる場合は、キャリブレーションダイアログのスライダーを使用して、プラスまたはマイナスのオフセット（例：-2.5 dB）を適用できます。このオフセットは、精度を向上させるために、今後のすべての測定（電話とウォッチ）に適用されます。これはすべてのユーザー向けの無料機能です。

## セッション履歴 {: data-toc-key="session-history" }

### 1. セッションを保存および管理するにはどうすればよいですか？ {: data-toc-key="manage-sessions" }
録音を一時停止した後、**保存** アイコンをタップします。履歴画面で、任意のセッションを **長押し** すると、選択モードに入ります。これにより、複数の録音を選択して、一度に削除したりお気に入りに登録したりできます。Wear OS ウォッチで録音されたセッションも、同期後にここに表示されます。

### 2. データをエクスポートするにはどうすればよいですか？ {: data-toc-key="exporting" }
セッションの詳細画面から、メニューを使用してデータをエクスポートできます。
-   **テキストとしてコピー：** この無料オプションは、セッションの簡単な要約をクリップボードにコピーします。
-   **CSVとしてエクスポート `[Plus+]`：** この premium 機能は、セッションのデシベル履歴のタイムスタンプ付きの完全なログをCSVファイルに保存し、スプレッドシートソフトウェアでの分析に最適です。

## Wear OS コンパニオン {: data-toc-key="wear-os" }

Wear OS 向けの Pixel Pulse アプリは、迅速な操作とスタンドアロンの録音のために設計されています。インターフェースの操作方法は次のとおりです：

### 1. スタンドアロン録音 {: data-toc-key="wear-recording" }
スマートフォンが手元になくても、ウォッチで直接セッションを録音できます。インターフェースは、バッテリーを節約するためにAMOLED画面に最適化されています。ウォッチで録音を終了すると、ローカルに保存できます。

### 2. 同期 {: data-toc-key="wear-sync" }
ウォッチがスマートフォンに再接続すると、保存されたセッションがスマートフォンのアプリの「履歴」タブに自動的に転送されます。この動作は、ウォッチの **設定 > 同期とバックアップ** で構成できます。

### 3. ナビゲーションの基本 {: data-toc-key="wear-nav" }
アプリは **水平レイアウト** を使用して、主要な機能を整理しています。画面を切り替えるには、**左** または **右** にスワイプします：
-   **中央：** メインメーター。
-   **右：** セッション履歴。
-   **右端：** 設定。

### 4. メインメーターの使用 {: data-toc-key="wear-meter" }
-   **録音の開始：** 大きな **再生** ボタンをタップして、モニタリングを開始します。
-   **没入モード：** 録音中に **画面をタップ** すると、停止/保存ボタンが非表示になります。これにより、デシベルの測定値が拡大され、リアルタイムの統計（最小/平均/最大）が表示されます。もう一度タップすると、コントロールが表示されます。
-   **クイック情報：** 下端から **上** にスワイプすると、現在のセッションのレイアウトやヒントに関する具体的な詳細が表示されます。

### 5. 履歴と詳細の表示 {: data-toc-key="wear-history" }
**履歴** 画面にスワイプして、録音のリストを表示します。
-   **セッションプレーヤー：** セッションをタップして詳細を開きます。最初の画面には、チャートと再生コントロールが表示されます。
-   **セッションアクション：** 詳細画面で **上** にスワイプすると、アクションメニューが表示されます。ここでは、特定のセッションの **名前変更**、**削除**、**お気に入り** への追加、またはスマートフォンへの手動での **同期** を行うことができます。

### 6. 設定とカスタマイズ {: data-toc-key="wear-settings" }
**設定** 画面（右端）にスワイプして、エクスペリエンスを構成します：
-   **メーター設定：** 更新速度と周波数特性 `[Plus+]` を調整するか、マイクロフォンをキャリブレーションします。
-   **カスタマイズ：** ウォッチフェイスに合わせてアプリのテーマカラーを変更します。
-   **同期とバックアップ：** セッションを自動的に同期するかどうかを構成します。

## Pixel Pulse+：サウンド曝露とアラート {: data-toc-key="plus-features" }

曝露タブは、Pixel Pulse+ エクスペリエンスの中心です。これにより、アプリは自動化された聴覚の健康コーチに変わります。

### 1. サウンド曝露分析とは何ですか？ {: data-toc-key="exposure-analysis" }
この `[Plus+]` 機能を有効にすると、アプリはバックグラウンドで静かに動作し、定期的に音のサンプルを取得して、周囲の環境の状況を構築します。これにより、複数のコンポーネントを備えた専用の画面が機能します：
-   **日次、週次、月次チャート：** さまざまな時間スケールで音のパターンを確認できます。
-   **週間ノイズ予算：** 大きな音（80 dB を超える音）への曝露を管理するのに役立つ、WHO のガイドラインに基づいた視覚的なツールです。
-   **主要な指標パネル：** 過去 24 時間の平均 dB、ピークレベル、および最も騒がしい/最も静かな時間帯を確認できます。
-   **パーソナライズされたインサイト：** アプリは、データの傾向に基づいて、コンテキストに応じたヒントや観察結果を提供します。

### 2. ノイズアラートはどのように機能しますか？ {: data-toc-key="noise-alerts" }
ノイズアラート `[Plus+]` はプロアクティブな安全機能です。曝露画面の設定で、**ノイズ制限**（例：85 dB）と **アラートの継続時間**（例：15分）を定義できます。指定した継続時間よりも長くその制限を超える環境にいたことをバックグラウンドモニターが検出した場合、通知が送信され、休憩をとるか聴覚保護具を使用するよう促されます。

### 3. 高度な `[Plus+]` 設定とは何ですか？ {: data-toc-key="advanced-settings" }
Pixel Pulse+ では、いくつかのプロ仕様の設定を利用できます：
-   **周波数特性（dBC/dBZ）：** dBA（人間の聴覚の標準）は無料ですが、Plus ユーザーは、技術分析のために dBC（低周波ノイズ用）または dBZ（フラットな非重み付け読み取り）に切り替えることができます。
-   **調整可能な更新速度：** メーターの応答速度を制御し、バッテリー寿命と急速な音の変化をキャプチャする必要性とのバランスを取ります。
-   **環境ハプティックフィードバック：** 周囲の音の強度に合わせて変化する、継続的で微妙な振動を有効にして、環境との独自の感覚的なつながりを提供します。

## データのプライバシーと取り扱い {: data-toc-key="data-privacy" }

お客様のプライバシーは最優先事項です。アプリがどのようなデータをどのように取り扱うかを正確に説明します。

### 1. リアルタイムメータリングと保存されたセッション（すべてのユーザー） {: data-toc-key="privacy-sessions" }
-   **音声は録音されますか？** いいえ。マイクロフォンは音圧を測定するために使用され、生の音声はすぐに破棄されます。**音声が保存されることは決してありません。**
-   **何が保存されますか？** セッションを保存すると、アプリは計算されたデシベル値のリスト（例：65.4、66.1、65.9）とセッションの統計（最小、最大、期間）を保存します。
-   **どこに保存されますか？** このデータは、**ご使用のデバイス上でのみ**、プライベートなローカルデータベースに保存されます。エクスポートを選択しない限り、スマートフォンから外部に送信されることはありません。

### 2. サウンド曝露モニタリング（Pixel Pulse+ ユーザー） {: data-toc-key="privacy-exposure" }
-   **どのように機能しますか？** 約 15 分ごとに、アプリが数秒間起動し、平均音量レベルを測定して、**タイムスタンプ** と 1つの **デシベル値** という 2つの情報を保存します。
-   **バックグラウンドで音声が録音されますか？** 絶対にありません。プロセスはリアルタイムメーターと同じで、即座に音声を測定、計算、および破棄します。
-   **このデータはどこに保存されますか？** これも、ご使用のデバイス上の同じプライベートなローカルデータベースに保存されます。
-   **データは共有されますか？** いいえ。すべての分析、チャート、およびインサイトは 100% デバイス上で生成されます。

### 3. 同期とバックアップ（Wear OS） {: data-toc-key="sync-data-privacy" }
-   **データはどのように転送されますか？** ウォッチからスマートフォンへセッションデータを転送するために、安全な **Android Wearable Data Layer API**（Google Play 開発者サービスの一部）を使用します。
-   **データはサーバーに保存されますか？** いいえ。Pixel Pulse には独自のバックエンドサーバーがありません。同期プロセスは厳密に **デバイス間** で行われます。
-   **クラウド同期についてはどうですか？** ウォッチとスマートフォンが Bluetooth で接続されていない場合、システムはデータの転送に Google Cloud Sync（暗号化）を使用して Wi-Fi/LTE 経由で中継することがあります。これは、配信を確保するために Android システムによって完全に処理されます。Pixel Pulse がこのデータに外部からアクセスしたり保存したりすることはありません。
-   **これを無効にすることはできますか？** はい。ウォッチの **設定 > 同期とバックアップ** メニューで、いつでも「自動同期」を無効にすることができます。

当社は、お客様の音声や測定データを収集、共有したり、それらにアクセスしたりすることは**ありません**。

## 手動バックアップと復元（.ppbk） {: data-toc-key="manual-backup" }

Pixel Pulse は、プライバシーを重視した堅牢な手動バックアップシステムを提供し、デバイス間でデータを転送したり、オフラインアーカイブを保持したりすることができます。このシステムは、独自のファイル形式である **`.ppbk`（Pixel Pulse Backup）** を使用します。

### 1. `.ppbk` ファイルとは何ですか？ {: data-toc-key="ppbk-format" }
`.ppbk` ファイルは、Pixel Pulse の履歴全体を保持する安全な暗号化されたコンテナです。単純なテキストや CSV のエクスポートとは異なり、このファイルには以下が含まれます：
-   **セッション録音：** 保存されたすべてのオーディオメータリングセッション。
-   **曝露履歴：** 長期的なバックグラウンドモニタリングデータ。
-   **メタデータ：** どのデバイス（スマートフォンまたはウォッチ）がデータを作成したか、およびアプリのバージョンに関する情報。

### 2. スマート復元（マージ戦略） {: data-toc-key="smart-restore" }
Pixel Pulse でのデータの復元は **非破壊的** です。「スマートマージ」戦略を使用しています：
-   **上書きなし：** バックアップを復元しても、既存のデータが削除されたり上書きされたりすることは **ありません**。
-   **重複の検出：** アプリは、すべてのセッションと曝露エントリの一意のタイムスタンプを確認します。
-   **シームレスな統合：** 現在デバイスに存在しないレコードのみをインポートします。これにより、重複を作成することなく、複数のバックアップや異なるデバイスからのデータを組み合わせることができます。

### 3. セキュリティと暗号化 {: data-toc-key="backup-security" }
サウンドデータは機密性が高いため、当社のバックアップはデフォルトで暗号化されています。テキストエディタで `.ppbk` ファイルを単に開くことはできません。
-   **暗号化標準：** NoPadding を使用した **AES-256-GCM**（Galois/Counter Mode での高度な暗号化標準）を使用しています。これは、機密データを保護するために使用される業界標準のアルゴリズムです。
-   **整合性チェック：** 復号化する前にファイルが破損または改ざんされていないことを確認するために、ファイルには一意の「マジックヘッダー」と初期化ベクトルが含まれています。

### 4. 使い方 {: data-toc-key="using-backup" }
-   **バックアップするには：** **設定 > データ管理 > バックアップ** に移動します。これにより `.ppbk` ファイルが生成され、Google Drive に保存したり、e-mail で送信したり、スマートフォンのファイルシステムに保存したりできます。
-   **復元するには：** **設定 > データ管理 > 復元** に移動し、有効な `.ppbk` ファイルを選択します。アプリがファイルを処理し、インポートされた新しいアイテムの数をお知らせします。

## トラブルシューティングとよくある質問 {: data-toc-key="troubleshooting" }

### 「マイクロフォンが他のアプリで使用されています」と表示されるのはなぜですか？ {: data-toc-key="mic-blocked" }
プライバシーとセキュリティの理由から、Android オペレーティングシステムは、一度に1つのアプリだけがマイクロフォンにアクセスすることを許可しています。電話をかけたり、音声メッセージを録音したり（例：WhatsAppで）、カメラを使用したりしている場合、Android は一時的に Pixel Pulse のハードウェアへのアクセスをブロックします。
- **手動録音：** マイクがブロックされている間に録音を開始しようとすると、警告が表示されます。すでに録音中で別のアプリが制御を引き継いだ場合、Pixel Pulse はデータの損失を防ぐために録音を適切に **一時停止** します。
- **ライブおよび継続的なセッション：** バックグラウンドセッションが実行されている場合、アプリは「待機」状態に入ります。ハードウェアを静かに監視し、通話や音声メモが終了するとすぐに自動的にトラッキングを **再開** します。お客様が何もする必要はありません！
- **これはエラーですか？** いいえ、これは Android の標準的な動作です。ただし、他のアプリがマイクロフォンを使用していないことが完全に確実で、問題が解決しない場合は、デバイスを再起動してみてください。問題が続く場合は、アプリからフィードバックをお送りください！

### バックグラウンドモニタリングが機能しなくなったようです。 {: data-toc-key="background-stop" }
一部のスマートフォンメーカーは、バックグラウンドアプリをシャットダウンする可能性のある積極的なバッテリー節約対策を使用しています。確実なモニタリングを確保するために、Pixel Pulse の **バッテリー最適化を無効** にしてください。最適化がアクティブであることを検出した場合、アプリは案内用のバナーを表示します。

### 測定値が不正確に思われます。 {: data-toc-key="readings-inaccurate" }
最良の結果を得るには、デバイスのメインマイクロフォンを音源に向け、覆われていないことを確認してください。**キャリブレーション** 機能を使用して、参照デバイスに対する測定値を微調整してください。
