# Pixel Pulse - Ajuda e Perguntas Frequentes {: data-toc-key="top" }

Bem-vindo à página de Ajuda e Perguntas Frequentes do Pixel Pulse! O nosso objetivo é ajudá-lo a medir e a compreender o seu ambiente acústico com precisão e clareza, seja no seu telefone ou no seu pulso.

## Primeiros passos {: data-toc-key="getting-started" }

### 1. Compreender a tela principal do medidor {: data-toc-key="main-screen" }
-   **Medidor de decibéis:** O medidor grande e semicircular fornece uma visualização em tempo real do nível de som atual. A sua cor muda dinamicamente para lhe dar um contexto instantâneo.
-   **Estatísticas da sessão:** As leituras MIN, AVG e MAX exibem as estatísticas da sua sessão de gravação atual.
-   **Botões de ação:**
    -   **Parar/Retomar:** O botão principal para pausar e continuar a medição.
    -   **Reiniciar:** Redefine todas as estatísticas da sessão e o temporizador.
    -   **Barra de ferramentas:** Ícones para acesso rápido à Calibração, ao Salvamento e a este guia de Informações.

### 2. Como funciona a Calibração? {: data-toc-key="calibration" }
A ferramenta de **Calibração** permite-lhe ajustar as leituras do aplicativo. Se você tiver acesso a um medidor de nível de som profissional, poderá usar o controle deslizante na caixa de diálogo de calibração para aplicar um deslocamento positivo ou negativo (por exemplo, -2,5 dB). Esse deslocamento será aplicado a todas as medições futuras (Telefone e Relógio) para melhorar a precisão. Esta é uma funcionalidade gratuita para todos os utilizadores.

## Histórico de sessões {: data-toc-key="session-history" }

### 1. Como guardo e faço a gestão de sessões? {: data-toc-key="manage-sessions" }
Após pausar uma gravação, toque no ícone **Salvar**. Na tela de Histórico, **pressione longamente** qualquer sessão para entrar no modo de seleção. Isso permite-lhe selecionar múltiplas gravações para excluí-las ou marcá-las como favoritas de uma só vez. As sessões gravadas no seu relógio Wear OS também aparecerão aqui após a sincronização.

### 2. Como exporto os meus dados? {: data-toc-key="exporting" }
A partir da tela de Detalhes da Sessão, você pode usar o menu para exportar os seus dados.
-   **Copiar como Texto:** Esta opção gratuita copia um resumo simples da sessão para a sua área de transferência.
-   **Exportar como CSV `[Plus+]`:** Este recurso premium salva um registro completo e com carimbo de data/hora do histórico de decibéis da sessão em um arquivo CSV, perfeito para análise em software de planilhas.

## Complemento para Wear OS {: data-toc-key="wear-os" }

O aplicativo Pixel Pulse para Wear OS foi projetado para interações rápidas e gravações independentes. Eis como navegar pela interface:

### 1. Gravação independente {: data-toc-key="wear-recording" }
Você pode gravar sessões diretamente no seu relógio sem que o seu telefone esteja presente. A interface é otimizada para telas AMOLED com o intuito de poupar bateria. Ao terminar uma gravação no relógio, você pode salvá-la localmente.

### 2. Sincronização {: data-toc-key="wear-sync" }
Quando o seu relógio se reconecta ao seu telefone, ele pode transferir automaticamente as suas sessões salvas para a aba de Histórico do aplicativo no telefone. Você pode configurar esse comportamento em **Configurações > Sincronização e Backup** no seu relógio.

### 3. Noções básicas de navegação {: data-toc-key="wear-nav" }
O aplicativo utiliza um **Layout Horizontal** para organizar as suas funcionalidades principais. Deslize para a **Esquerda** ou para a **Direita** para alternar entre as telas:
-   **Centro:** O Medidor Principal.
-   **Direita:** Histórico de Sessões.
-   **Extrema Direita:** Configurações.

### 4. Usar o Medidor Principal {: data-toc-key="wear-meter" }
-   **Iniciar Gravação:** Toque no botão grande de **Reproduzir** para iniciar o monitoramento.
-   **Modo Imersivo:** Durante a gravação, **toque na tela** para ocultar os botões de Parar/Salvar. Isso amplia a leitura de decibéis e revela as estatísticas em tempo real (Min/Avg/Max). Toque novamente para exibir os controles.
-   **Informações Rápidas:** Deslize para **Cima** a partir da borda inferior para visualizar detalhes específicos sobre o layout da sessão atual ou dicas.

### 5. Visualizar Histórico e Detalhes {: data-toc-key="wear-history" }
Deslize para a tela de **Histórico** para visualizar a sua lista de gravações.
-   **Reprodutor de Sessões:** Toque em qualquer sessão para abrir os detalhes. A primeira tela exibe um gráfico e controles de reprodução.
-   **Ações da Sessão:** Na tela de detalhes, deslize para **Cima** para revelar o menu de ações. Aqui você pode **Renomear**, **Excluir**, **Favoritar** ou **Sincronizar** manualmente aquela sessão específica com o seu telefone.

### 6. Configurações e Personalização {: data-toc-key="wear-settings" }
Deslize para a tela de **Configurações** (extrema direita) para configurar a sua experiência:
-   **Configurações do Medidor:** Ajuste a Velocidade de Atualização e a Ponderação de Frequência `[Plus+]` ou Calibre o microfone.
-   **Personalização:** Altere a cor do tema do aplicativo para corresponder ao mostrador do seu relógio.
-   **Sincronização e Backup:** Configure se as sessões são sincronizadas de forma automática.

## Pixel Pulse+: Exposição Sonora e Alertas {: data-toc-key="plus-features" }

A aba de Exposição é o núcleo da experiência do Pixel Pulse+. Ela transforma o aplicativo em um treinador automatizado de saúde auditiva.

### 1. O que é a Análise de Exposição Sonora? {: data-toc-key="exposure-analysis" }
Quando você ativa esta funcionalidade `[Plus+]`, o aplicativo atua de forma silenciosa em segundo plano e coleta amostras de som periódicas para construir um panorama do seu ambiente. Isso alimenta uma tela dedicada com vários componentes:
-   **Gráficos Diários, Semanais e Mensais:** Visualize os seus padrões sonoros em diferentes escalas de tempo.
-   **Orçamento de Ruído Semanal:** Uma ferramenta visual baseada nas diretrizes da OMS para ajudá-lo a gerir a sua exposição a sons altos (acima de 80 dB).
-   **Painel de Métricas Principais:** Visualize a sua média de dB, níveis de pico e os períodos mais movimentados/mais silenciosos das últimas 24 horas.
-   **Informações Personalizadas:** O aplicativo fornece dicas contextuais e observações com base nas tendências dos seus dados.

### 2. Como funcionam os Alertas de Ruído? {: data-toc-key="noise-alerts" }
Os Alertas de Ruído `[Plus+]` são um recurso de segurança proativo. Nas configurações da tela de Exposição, você pode definir um **Limite de Ruído** (por exemplo, 85 dB) e uma **Duração do Alerta** (por exemplo, 15 minutos). Se o monitor em segundo plano detetar que você permaneceu em um ambiente que excede esse limite por mais tempo do que a duração especificada, ele lhe enviará uma notificação, como um lembrete para fazer uma pausa ou usar proteção auditiva.

### 3. Quais são as Configurações Avançadas `[Plus+]`? {: data-toc-key="advanced-settings" }
O Pixel Pulse+ desbloqueia diversas configurações de nível profissional:
-   **Ponderação de Frequência (dBC/dBZ):** Embora a opção dBA (o padrão para a audição humana) seja gratuita, os utilizadores Plus podem alternar para dBC (para ruído de baixa frequência) ou dBZ (uma leitura plana e não ponderada) para análise técnica.
-   **Velocidade de Atualização Ajustável:** Controle a rapidez com que o medidor responde, equilibrando a vida útil da bateria com a necessidade de capturar mudanças sonoras rápidas.
-   **Feedback Háptico Ambiental:** Ative uma vibração contínua e sutil que acompanha a intensidade do som ambiente, de modo a proporcionar uma conexão sensorial única com o seu entorno.

## Privacidade e Tratamento de Dados {: data-toc-key="data-privacy" }

A sua privacidade é fundamental. Eis exatamente quais os dados que o aplicativo trata e de que forma.

### 1. Medição em Tempo Real e Sessões Salvas (Todos os Utilizadores) {: data-toc-key="privacy-sessions" }
-   **O áudio é gravado?** Não. O microfone é utilizado para medir a pressão sonora, e o áudio bruto é descartado de imediato. **Nenhum áudio é salvo em momento algum.**
-   **O que é salvo?** Ao salvar uma sessão, o aplicativo armazena uma lista de números de decibéis calculados (por exemplo, 65.4, 66.1, 65.9) e estatísticas da sessão (min, max, duração).
-   **Onde fica armazenado?** Estes dados são armazenados em um banco de dados local e privado, **apenas no seu dispositivo**. Eles nunca saem do seu telefone, a menos que você opte por exportá-los.

### 2. Monitoramento de Exposição Sonora (Utilizadores do Pixel Pulse+) {: data-toc-key="privacy-exposure" }
-   **Como funciona?** A cada 15 minutos, aproximadamente, o aplicativo desperta por alguns segundos, mede o nível de som médio e salva duas informações: um **carimbo de data/hora** e um único **número de decibéis**.
-   **O áudio é gravado em segundo plano?** Absolutamente não. O processo é o mesmo do medidor em tempo real: medir, calcular e descartar o áudio instantaneamente.
-   **Onde esses dados são armazenados?** Eles também são armazenados no mesmo banco de dados local e privado no seu dispositivo.
-   **Algum dado é partilhado?** Não. Todas as análises, gráficos e informações são gerados 100% no próprio dispositivo.

### 3. Sincronização e Backup (Wear OS) {: data-toc-key="sync-data-privacy" }
-   **Como ocorre a transferência dos dados?** Utilizamos a segura **API Android Wearable Data Layer** (parte do Google Play Services) para transferir os dados da sessão do seu Relógio para o seu Telefone.
-   **Os dados são armazenados em servidores?** Não. O Pixel Pulse não possui servidores de backend próprios. O processo de sincronização é estritamente de **Dispositivo para Dispositivo**.
-   **E quanto ao Cloud Sync?** Se o seu relógio e o seu telefone não estiverem conectados via Bluetooth, o sistema poderá usar o Google Cloud Sync (criptografado) para retransmitir os dados via Wi-Fi/LTE. Isso é gerido integralmente pelo Sistema Android para garantir a entrega; o Pixel Pulse não acessa nem armazena esses dados de forma externa.
-   **Posso desativar isso?** Sim. Você pode desativar a "Sincronização Automática" no menu **Configurações > Sincronização e Backup** do seu relógio a qualquer momento.

Nós **não** coletamos, não partilhamos e não temos qualquer acesso ao seu áudio ou aos seus dados de medição.

## Backup Manual e Restauração (.ppbk) {: data-toc-key="manual-backup" }

O Pixel Pulse oferece um sistema de backup manual robusto e focado na privacidade, o que lhe permite transferir os seus dados entre dispositivos ou manter arquivos offline. Esse sistema utiliza um formato de arquivo proprietário: **`.ppbk` (Backup do Pixel Pulse)**.

### 1. O que é um arquivo `.ppbk`? {: data-toc-key="ppbk-format" }
Um arquivo `.ppbk` é um contêiner seguro e criptografado que guarda todo o seu histórico do Pixel Pulse. Diferente de exportações simples em texto ou CSV, este arquivo contém:
-   **Gravações de Sessão:** Todas as suas sessões salvas de medição de áudio.
-   **Histórico de Exposição:** Os seus dados de monitoramento em segundo plano de longo prazo.
-   **Metadados:** Informações sobre qual dispositivo (Telefone ou Relógio) gerou os dados e a versão do aplicativo.

### 2. Restauração Inteligente (Estratégia de Mesclagem) {: data-toc-key="smart-restore" }
A restauração de dados no Pixel Pulse **não é destrutiva**. Utilizamos uma estratégia de "Mesclagem Inteligente":
-   **Sem Substituição:** A restauração de um backup **não** excluirá nem substituirá os seus dados existentes.
-   **Deteção de Duplicatas:** O aplicativo verifica o carimbo de data/hora exclusivo de cada sessão e entrada de exposição.
-   **Integração Contínua:** Ele apenas importa os registos que não existem atualmente no seu dispositivo. Isso permite-lhe combinar dados de múltiplos backups ou de dispositivos diferentes sem criar duplicatas.

### 3. Segurança e Criptografia {: data-toc-key="backup-security" }
Os seus dados sonoros são confidenciais, pelo que os nossos backups são criptografados por padrão. Não é possível simplesmente abrir um arquivo `.ppbk` num editor de texto.
-   **Padrão de Criptografia:** Utilizamos **AES-256-GCM** (Advanced Encryption Standard in Galois/Counter Mode) com NoPadding. Este é um algoritmo padrão da indústria utilizado para proteger dados confidenciais.
-   **Verificação de Integridade:** O arquivo inclui um "Cabeçalho Mágico" exclusivo e vetores de inicialização para garantir que o arquivo não foi corrompido ou adulterado antes da descriptografia.

### 4. Como utilizá-lo {: data-toc-key="using-backup" }
-   **Para fazer Backup:** Aceda a **Configurações > Gestão de Dados > Backup**. Isto irá gerar um arquivo `.ppbk` que você poderá salvar no Google Drive, enviar por e-mail ou armazenar no sistema de arquivos do seu telefone.
-   **Para Restaurar:** Aceda a **Configurações > Gestão de Dados > Restaurar** e selecione um arquivo `.ppbk` válido. O aplicativo processará o arquivo e informá-lo-á sobre quantos itens novos foram importados.

## Resolução de Problemas e Perguntas Frequentes {: data-toc-key="troubleshooting" }

### Por que motivo exibe a mensagem "Microfone em uso por outro aplicativo"? {: data-toc-key="mic-blocked" }
Por razões de privacidade e segurança, o sistema operacional Android permite que apenas um aplicativo acesse o microfone de cada vez. Se você realizar uma chamada telefônica, gravar uma mensagem de voz (por exemplo, no WhatsApp) ou utilizar a câmera, o Android bloqueará temporariamente o acesso do Pixel Pulse ao hardware.
- **Gravação Manual:** Se você tentar iniciar uma gravação enquanto o microfone estiver bloqueado, verá um aviso. Se já houver uma gravação em andamento e outro aplicativo assumir o controle, o Pixel Pulse **pausará** a sua gravação de forma adequada para evitar a perda de dados.
- **Sessões Contínuas e ao Vivo:** Se uma sessão em segundo plano estiver ativa, o aplicativo entrará num estado de "Espera". Ele monitorará o hardware de forma silenciosa e retomará o rastreamento de forma automática assim que a sua chamada ou nota de voz for concluída. Você não precisa fazer nada!
- **Isso é um erro?** Não, este é o comportamento padrão do Android. No entanto, se você tiver certeza absoluta de que nenhum outro aplicativo utiliza o microfone e o problema persistir, experimente reiniciar o seu dispositivo. Se o problema continuar, por favor, envie-nos o seu feedback através do aplicativo!

### O monitoramento em segundo plano parece parar de funcionar. {: data-toc-key="background-stop" }
Alguns fabricantes de telefones utilizam medidas agressivas de economia de bateria que podem encerrar aplicativos em segundo plano. Para garantir um monitoramento confiável, por favor, **desative a Otimização de Bateria** para o Pixel Pulse. O aplicativo exibirá um banner para orientá-lo caso detete que a otimização se encontra ativa.

### As minhas leituras parecem imprecisas. {: data-toc-key="readings-inaccurate" }
Para obter os melhores resultados, aponte o microfone principal do seu dispositivo em direção à fonte de som e certifique-se de que ele não está coberto. Utilize o recurso de **Calibração** para ajustar as leituras em relação a um dispositivo de referência.
